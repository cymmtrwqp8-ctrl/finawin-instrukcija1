# Konfigurācija

Šī izvēlne paredzēta sistēmas parametru un uzstādījumu konfigurēšanai, lai pielāgotu vidi uzņēmuma vajadzībām:

**Parametru noskaņošana** - galvenā sadaļa, kurā tiek definēti sistēmas vispārīgie uzstādījumi (datumi, valūtas, darbības parametri u.c.).

**Noskaņot lietotāja rīkjoslu** - ļauj pielāgot rīkjoslas izkārtojumu, izvēloties, kuras funkcijas vai ikonas būs redzamas ātrai piekļuvei.

**Dokumentu tipi (F4)** - nosaka dokumentu klasifikāciju (piemēram, rēķins, pavadzīme, maksājums), kas tiek izmantota uzskaitē un atskaitēs.

**Atskaišu noskaņas** - sadaļa, kur var pielāgot atskaišu parametrus, izkārtojumu un filtrus.

**Analītikas kontrole** - nodrošina analītisko dimensiju uzraudzību, lai grāmatojumi atbilstu noteiktajiem klasifikatoriem (projektiem, aģentiem u.c.).

**Bankas importa noskaņas** - uzstādījumi bankas failu importam un automātiskai saskaņošanai ar grāmatvedības datiem.

**Sasaistāmie konti** - tiek definēti kontu savienojumi (piem., debeta un kredīta konti, automatizētām darbībām).

**PVN kodi** - PVN likmju un uzskaites kodu saraksts, kas nepieciešams rēķinu un atskaišu sagatavošanai.

**Pakalpojumu katalogs** - vienots preču/pakalpojumu saraksts, ko izmanto dokumentos un grāmatojumos, nodrošinot konsekvenci un klasifikāciju.
