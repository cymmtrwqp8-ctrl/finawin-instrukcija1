#  Noskaņošana un pielāgošana

Šajā materiālā aprakstīts standarta darbs ar programmu.

Gadījumos, ja tiek veikta īpaša programmas noskaņošana vai funkciju izstrāde, kas paredzēta tieši Jūsu uzņēmuma specifiskajām vajadzībām, būs nepieciešama papildu apmācība- attālināti vai klātienē, vai izstrādāta papildu instrukcija tieši šīs funkcionalitātes lietošanai.
