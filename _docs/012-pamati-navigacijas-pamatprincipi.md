# NAVIGĀCIJAS PAMATPRINCIPI

Lai nodrošinātu ērtu ikdienas darbu programmā, nepieciešams iepazīties ar programmas navigācijas principiem - darbu ar programmas funkcionālajām pogām un pamatprincipiem darbā ar lielu informācijas apjomu, dažādu datu un ierakstu apstrādāšanu.
