## Navigācija, izmantojot tastatūru

| **←, ↑, →, ↓** | kursora pārvietošana pa sarakstu un laukiem |
|----------------|---------------------------------------------|
| **Insert**     | jauns ieraksts                              |
| **Ctrl+Del**   | dzēst ierakstu                              |
| **Enter**      | pāreja konkrēta lauka rediģēšanas režīmā    |
| **Esc**        | atcelt izmaiņas                             |
| **Ctrl+Home**  | aiziet uz saraksta sākumu                   |
| **Ctrl+End**   | aiziet uz saraksta beigām                   |

**Pieejamas arī papildu opcijas darbam ar katalogiem:**

| **PageUp**                                                                                                            | iepriekšējā lapaspuse                   |
|-----------------------------------------------------------------------------------------------------------------------|-----------------------------------------|
| **PageDown**                                                                                                          | nākamā lapaspuse                        |
| **Home**                                                                                                              | kārtējā ieraksta pirmais lauks          |
| **End**                                                                                                               | kārtējā ieraksta pēdējais lauks         |
| **Ctrl+PageUp**                                                                                                       | pāreja uz lapaspuses pirmo ierakstu     |
| **Ctrl+PageDown**                                                                                                     | pāreja uz lapaspuses pēdējo ierakstu    |
| **Shift+Tab**                                                                                                         | pāreja uz iepriekšējo lauku (uz augšu)  |
| **Tab**                                                                                                               | pārvietošanās uz nākamo lauku (uz sānu) |
| Burta, cipara, speciālā simbola, kā arī **BackSpace** piespiešana izdzēsīs lauka saturu un pāries rediģēšanas režīmā. |                                         |

**Taustiņi, kas tiek izmantoti rediģēšanas režīmā:**

| Bultas pa labi un pa kreisi (arī ar piespiestu taustiņu Ctrl), Home, End - kursora pārvietošana pa lauku. Ja vienlaicīgi piespiests taustiņš Shift, tad lauka saturs tiks iezīmēts daļēji. |                                                                         |
|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------|
| **Delete**                                                                                                                                                                                 | dzēst simbolu pēc kursora                                               |
| **BackSpace**                                                                                                                                                                              | dzēst simbolu pirms kursora                                             |
| **Shift+Delete**                                                                                                                                                                           | nodzēst iezīmēto lauka daļu un saturu saglabāt Clipboard (Starpliktuvē) |
| **Ctrl+Insert, Ctrl+C**                                                                                                                                                                    | iezīmētās lauka daļas ierakstīšana Clipboard                            |
| **Shift+Insert, Ctrl+V, Ctrl+V**                                                                                                                                                           | atjaunot tekošo lauku no Clipboard                                      |
| **Esc**                                                                                                                                                                                    | atcelt pēdējās izmaiņas                                                 |

Taustiņu kombinācijas, kas **paredzētas sarakstu** vai **katalogu atvēršanai** un **funkciju izsaukšanai:**

> **F4** - Dokumentu tipi
>
> **F7** - Kopēt augšēja ieraksta vērtību
>
> **Ctrl+F7** - Kopēt izvēlēto ierakstu
>
> **Ctrl+F /Ctrl+M** - Meklēšana
>
> **Ctrl+A** - Atjaunot datus tekošajā tabulā
>
> **Ctrl+J** - Jauna virsgrāmatas dokumenta izveide
>
> **Ctrl+K** - Tabulas konfigurācija
>
> **Ctrl+L** - Izsauc kalkulatoru datorā
>
> **Ctrl+O** - Tabulas sakārtošana
>
> **Ctrl+Q** - Komandu meklēšana
>
> **Ctrl+T** - Tekošais datums
>
> **Ctrl+Alt+F** - Meklēt kolonnu tabulā
>
> **Ctrl+Delete** - Dzēst rindu
>
> **Ctrl+Enter** - Saglabāt ierakstu
