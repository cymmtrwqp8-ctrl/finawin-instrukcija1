# FinaWin instrukcija — GitHub Pages

Šajā mapē ir pilns FinaWin instrukcijas avots: 10 moduļi, 76 rediģējamas sadaļas un ekrānattēli.

## 1. Pirmā publicēšana GitHub

1. Atveriet https://github.com/new.
2. Izveidojiet repozitoriju, piemēram, finawin-instrukcija.
3. Atveriet jauno repozitoriju un izvēlieties Add file → Upload files.
4. Vispirms atarhivējiet šo ZIP savā datorā.
5. GitHub logā ievelciet visu atarhivētās mapes saturu. Neaugšupielādējiet pašu ZIP failu.
6. Nospiediet Commit changes.
7. Atveriet Settings → Pages.
8. Pie Build and deployment / Source izvēlieties Deploy from a branch.
9. Izvēlieties zaru main, mapi /(root) un nospiediet Save.
10. Pēc dažām minūtēm tajā pašā sadaļā būs redzama publicētās vietnes adrese.

## 2. Kolēģa pievienošana

1. Repozitorijā atveriet Settings → Collaborators.
2. Nospiediet Add people.
3. Norādiet kolēģa GitHub lietotājvārdu vai e-pastu.
4. Kolēģim jāpieņem GitHub uzaicinājums.

## 3. Instrukcijas teksta labošana

1. Atveriet mapi _docs.
2. Atveriet vajadzīgo .md failu.
3. Nospiediet zīmuļa ikonu Edit this file.
4. Izlabojiet tekstu un nospiediet Commit changes.
5. GitHub Pages automātiski publicēs izmaiņas.

Katras sadaļas sākumā ir tehniskā daļa starp --- līnijām. Laukus module, order, layout un permalink nemainiet, ja nevēlaties pārvietot sadaļu.

## 4. Attēlu pievienošana

Attēlus glabājiet mapē assets/images. Kā paraugu attēla ievietošanai izmantojiet jau esošo attēlu pierakstu instrukcijas failos.

## 5. Klienta moduļu saite

Vietnē nospiediet Klienta moduļi, atzīmējiet iegādātos moduļus un nospiediet Kopēt klienta saiti.

Svarīgi: moduļu saite ir ērts skats, nevis drošības mehānisms. Ja klients nedrīkst tehniski piekļūt pārējiem moduļiem, viņam jāveido atsevišķs GitHub Pages repozitorijs ar tikai atļautajiem _docs failiem.

## 6. Publiskums

GitHub Pages vietne ir publiski atverama. Neievietojiet instrukcijā paroles, klientu personas datus, slepenas serveru adreses vai citu konfidenciālu informāciju.
